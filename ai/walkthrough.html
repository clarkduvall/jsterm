Web LLM Prompt API

An interactive guide to the future of on-device AI in the browser.

The Web LLM Prompt API gives web developers direct access to large language models running entirely on a user's device. This on-device approach offers significant benefits, including enhanced privacy (user data never leaves the machine) and the ability to run offline once the model is downloaded.

The API is available via an Origin Trial starting in Chrome 139, or by enabling the chrome://flags/#prompt-api-for-gemini-nano-multimodal-input flag in your browser. For more information, check out the official documentation.

1. Checking Availability

Before trying to create a model session, you should check if the browser supports the API and if the required model data is ready. The LanguageModel.availability() method returns the status, which can be available, downloadable, downloading, or unavailable.

const availability = await LanguageModel.availability();
addOutput(`Model availability: ${availability}`);


                

            

        


        
        

            
2. Creating a Session & Handling Downloads

            
If the model isn't available locally, creating a session with LanguageModel.create() may trigger a download. You can show the progress to the user with the monitor option.

             

                
const session = await LanguageModel.create({
    monitor: (monitor) => {
        monitor.addEventListener("downloadprogress", (e) => {
             // e.loaded is a value between 0 and 1
            const percent = Math.round(e.loaded * 100);
            addOutput(`Downloading... ${percent}%`, true);
        });
    }
});
addOutput("Session created! Download (if any) is complete.", true);


            

            

                
                

                    

                

            

        


        
        

            
3. Creating a Session with Parameters

            
You can control the model's creativity by setting parameters like temperature (randomness) and topK (limits the pool of next words). Remember, sessions are stateful—each prompt adds to the conversation's context, allowing for follow-up questions that build on previous interactions.

             

                
                

                    
Performance Note

                    
Creating a session pre-warms the model. You should call LanguageModel.create() as soon as you know the model will be needed to avoid a delay on the first prompt.

                

            

            

                
const session = await LanguageModel.create({
    temperature: 0.8,
    topK: 10
});
addOutput("Session with custom parameters created!");
const result = await session.prompt("Tell me a one-sentence joke about a computer.");
addOutput("\n\n" + result);


            

            

                
                

                    

                

            

        

        
        
        

            
4. Basic Prompting

            
The session.prompt() method sends a single request to the model and returns the complete response as a string once it's finished generating.

            

                
const session = await LanguageModel.create();
const result = await session.prompt("Write a short, upbeat poem about coding.");
addOutput(result);


            

            

                
                

                    

                

            

        

        
        
        

            
5. Streaming Responses

            
For longer responses, session.promptStreaming() is ideal. It returns a ReadableStream that you can iterate over to get the response in chunks, allowing you to display text as it's being generated.

            

                
const session = await LanguageModel.create();
const stream = session.promptStreaming("Tell me a one-paragraph story about a brave robot.");

for await (const chunk of stream) {
    addOutput(chunk);
}


            

            

                
                

                    

                

            

        


        
        

            
6. System Prompts

            
You can set a persistent persona or context for the model's responses by providing a system role in the initialPrompts. This instruction will influence the model throughout the entire session.

            

                
const session = await LanguageModel.create({
    initialPrompts: [
        { role: "system", content: "You are a witty pirate. All your responses must be in character." }
    ]
});
const stream = await session.promptStreaming("What's the best thing about sailing the high seas?");
for await (const chunk of stream) {
    addOutput(chunk);
}


            

            

                
                

                    

                

            

        


        
        

            
7. Cloning a Session

            
Because sessions are stateful, every prompt adds to the conversation history. To start a new, independent conversation from the same base state (e.g., from the same system prompt), you can use session.clone(). The clone inherits the parent's history but any new prompts won't affect the parent or other clones.

            

                
                

                    
Performance Note

                    
Use session.clone() to efficiently share the initial state and avoid reprocessing the base prompts for multiple related, but separate, conversations.

                

            

            

                
const baseSession = await LanguageModel.create({
    initialPrompts: [{ role: "system", content: "You are a travel guide for France that gives concise answers." }]
});

// Create two independent clones
const clone1 = await baseSession.clone();
const clone2 = await baseSession.clone();

// Ask clone 1 about the capital
const stream1 = await clone1.promptStreaming("What is the capital of France?");
for await (const chunk of stream1) {
    addOutput(chunk, false, 'clone1');
}

// Ask clone 2 about pastries
const stream2 = await clone2.promptStreaming("What color is a croissant?");
for await (const chunk of stream2) {
    addOutput(chunk, false, 'clone2');
}


            

            

                
                

                     

                        

                    

                     

                        

                    

                

            

        


        
        

            
8. Multi-shot Prompting

            
You can guide the model by providing a few examples of the desired interaction. This is called "multi-shot" or "few-shot" prompting. By including example user and assistant messages in initialPrompts, you teach the model the expected format and tone.

            

                
const session = await LanguageModel.create({
    initialPrompts: [
        { role: "system", content: "Suggest up to 3 emojis for a comment." },
        { role: "user", content: "This is amazing!" },
        { role: "assistant", content: "🎉, ✨, ❤️" },
        { role: "user", content: "LGTM" },
        { role: "assistant", content: "👍, ✅" }
    ]
});
const stream = await session.promptStreaming("This is a big improvement!");
for await (const chunk of stream) {
    addOutput(chunk);
}


            

            

                
                

                    

                

            

        


        
        

            
9. Multi-modal Input

            
The API can accept non-text inputs like images. To do this, you specify expectedInputs when creating the session. The content of a prompt can then be an array of different types. Here, we provide a drawing from a canvas element.

            

                
This canvas provides an image for the example:

                
            

            

                
const session = await LanguageModel.create({
    expectedInputs: [{ type: "image" }]
});

// The userDrawnImage can be any ImageBitmapSource, like an  or 
const userDrawnImage = document.getElementById('mock-canvas');

const stream = await session.promptStreaming([{
    role: "user",
    content: [
        { type: "text", value: "Describe the image." },
        { type: "image", value: userDrawnImage }
    ]
}]);

for await (const chunk of stream) {
    addOutput(chunk);
}


            

            

                
                

                    

                

            

        

        
        
        

            
10. Structured Output

            
You can constrain the model's output to a specific format using responseConstraint. This is incredibly useful for getting predictable data structures, like JSON that matches a schema or text that matches a regular expression. This example uses prompt() for a non-streaming response.

            
JSON Schema

            

                
const schema = {
    type: "object",
    properties: {
        city: { type: "string", description: "The city name." },
        country: { type: "string", description: "The country name." },
    },
    required: ["city", "country"]
};

const session = await LanguageModel.create();
const result = await session.prompt(
    "What is the capital of France?",
    { responseConstraint: schema }
);

const parsed = JSON.parse(result);
addOutput(JSON.stringify(parsed, null, 2));


            

             

                
                

                    

                

            


            
Regular Expression

            

                
const hexColorRegExp = /^#[0-9a-fA-F]{6}$/;

const session = await LanguageModel.create();
const result = await session.prompt(
    "Give me a hex code for a calm blue color.",
    { responseConstraint: hexColorRegExp }
);

addOutput(result);


            

             

                
                

                    

                

            

        


        
        

            
11. Using a Prefix

            
You can guide the model by pre-filling the beginning of its response. By adding prefix: true to the last assistant message, you force the model's output to start with your specified text. This is useful for ensuring a specific format without showing the prefix instruction to the user.

            

                
const session = await LanguageModel.create();

const stream = await session.promptStreaming([
  {
    role: "user",
    content: "Create a TOML character sheet for a gnome barbarian. Keep it short and give no additional explanations."
  },
  {
    role: "assistant",
    content: "```toml\n", // The model will continue from here
    prefix: true
  }
]);

for await (const chunk of stream) {
    addOutput(chunk);
}


            

            

                
                

                    

                

            

        


        
        

            
12. Appending Messages with append()

            
The append() method lets you add messages to the session's context without immediately generating a response. This is useful for building up a conversation or providing data incrementally before asking for a final result.

            

                
                

                    
Performance Note

                    
Use session.append() to pre-process large or complex inputs (like images or long documents) before the user submits the final prompt, hiding latency.

                

            

            

                
const session = await LanguageModel.create();

// Add messages to the session's history without getting a response.
// Note: append() expects an array of messages.
await session.append([{role: "user", content: "Fact 1: The sky is blue."}]);
await session.append([{role: "user", content: "Fact 2: Grass is green."}]);

addOutput("Appended two facts to the session context.\n\nNow, asking for a summary...\n\n");

// Now prompt for a response based on the full context.
const stream = await session.promptStreaming("Summarize the facts I've given you in a single sentence.");

for await (const chunk of stream) {
    addOutput(chunk);
}


            

            

                
                

                    

                

            

        


        
        

            
13. Aborting a Prompt

            
For long-running requests, you can provide an AbortSignal. Calling abort() on the associated AbortController will stop the generation and reject the promise. This gives the user control over expensive or unwanted operations.

            

                
const controller = new AbortController();

// Make the controller globally accessible for the Abort button.
window.abortExampleController = controller;

const session = await LanguageModel.create();
const stream = session.promptStreaming(
    "Tell me the entire history of the universe, in great detail, starting from the big bang.",
    { signal: controller.signal }
);

for await (const chunk of stream) {
    addOutput(chunk);
}
